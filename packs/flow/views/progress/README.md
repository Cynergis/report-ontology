# How it is built

The flow pack's page in the product's studio (`place: build`): the flow the product runs, its steps
in order (what kind each is, what it reads and writes, the checks that guard it, the settings it
depends on, where the run goes next, and whether it is built yet), what it produces, its checks and
settings, and the tests it still owes. The flow's open questions (`FL`) are listed at the bottom: what
an implementing agent still lacks.
