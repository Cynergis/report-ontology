# The reports

The report pack's page in the product's studio (`place: domain`): each report type the product
produces, its purpose, audience, cadence and languages, what identifies a document, the table its data
comes from (and, with the report-medallion bridge, the pipeline's dataset and field behind each
column), its rules, its sections and fields with what each means in each language and where it comes
from, when it runs and where it goes, and its history. The report questions' gaps (`Q`, and `RP` in a
report product) are listed at the bottom.
